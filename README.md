# Lynails - Plataforma Web de Servicios de Belleza

Sitio web interactivo y responsivo desarrollado para la gestión de turnos, catálogo de servicios y contacto del emprendimiento **Lynails**.



## Documentación e Informe
Puedes consultar el informe completo del proyecto en el siguiente archivo:
  **[Ver Informe Técnico / Académico](./doc-practicas-final.pdf)**



##  Demo en Vivo
Puedes visitar la aplicación desplegada aquí: **[Ver sitio web en vivo]( https://lynailssss.netlify.app)**



##  Tecnologías Utilizadas
 **HTML:** Estructura semántica de la interfaz.
 **CSS:** Estilos personalizados, diseño responsivo y layout moderno.
 **JavaScript:** Lógica de interacción, validación de formularios y dinámica del sitio.
 **Netlify:** Despliegue y hosting.



##  Características Principales
  **Diseño Responsivo:** Adaptado a dispositivos móviles, tablets y computadora.
  **Formulario de Reservas:** Solicitud de turnos y validación de datos.
  **Catálogo de Servicios:** Muestra detallada de tratamientos y tarifas.
  **Sección de Contacto:** Acceso directo a redes y WhatsApp.
